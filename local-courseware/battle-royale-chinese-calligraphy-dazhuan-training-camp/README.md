# 铸铭问鼎论英雄 · 大篆训练营

「趣味游戏互动 HTML 课件集」三部曲之中篇（西周）：商 · 甲骨小侦探 → **西周 · 铸铭问鼎论英雄** → 秦 · 篆刻工坊。

面向中学预备班书法课的课堂互动课件：以"西周铸铭工匠"角色扮演为叙事壳，学生在**识铭、辨铭、写铭（描红）、铸鼎、双人 PK** 五类玩法中学习约 35 个金文（大篆主体）的认读与书写。

## 特性

- **单文件零依赖**：`铸铭问鼎论英雄-大篆训练营-V3.html` 双击即用，file:// 离线可跑，外部请求 0
- **描红评分引擎 v3.2**：SVG 轮廓运行时骨架化 → 双向 Chamfer 距离 → S 形软映射四维评分（贴合/覆盖/出界/经济性），支持触屏多点
- **双人混合赛**：辨铭抢答（先答 +15/后答 +10）+ 写铭分屏描红，轮数随难度（菜鸟 6+4 / 困难 9+6 / 梦魇 12+8）
- **铸鼎仪式 / 拓片收集墙（金框巡游）/ 揭榜爬榜动画 / 成就系统 / 成绩导出导入**
- 全部字形为内嵌 SVG，零字体授权风险；字形数据来源 [etymology-svg](https://cnb.cool/e8so/etymology-svg) 开源字库（课件内已注明出处，**公开发布前请自行确认授权**）

## 复现流程

```bash
node tools/calibrate.js   # 真机校准（35 字骨架/相似字表/限时模型，证据归档 docs/）
node tools/build.js       # 源码分片构建 → 单文件 HTML（构建期断言 + 语法闸门）
node tools/test_main.js   # 85 项真机测试（Playwright + 系统 Chrome）
node tools/shot.js        # 全流程截图
```

源码分片在 `src/`（p1 骨架 CSS / p2 数据+引擎 / p3 单人玩法 / p4 双人对决+揭榜+成绩管理），工具在 `tools/`。
