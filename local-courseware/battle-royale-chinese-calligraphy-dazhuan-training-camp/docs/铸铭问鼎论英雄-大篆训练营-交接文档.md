## 5. 架构真相（改代码前必读）

1. **源码分片 + 构建拼装**：改 src/ 分片 → `node tools/build.js` 重建 → 测试只打构建产物。构建期断言：35 字齐/DZINFO 齐/GLYPHS 齐/SCRIPT 无 seal 残留/拼接语法（node --check）/零外链/体积上限/**校准证据与 CHARS 一致**。
2. **go(i) 是唯一入口**：每页渲染函数挂在 go() 的 R 数组；冷启动直跳任何页不得白屏/崩（有守卫）。离屏 slide 一律清空 innerHTML（防跨屏重复 id）。
3. **每页首屏必须有出口**（顶栏 ⌂ 恒在 + 页内按钮）。
4. **描红引擎 v3.2**：基准 = 字形骨架中心线（非填充区）；笔迹分段存储（pointerdown 分笔）；判定显式传字；S 形软映射（容差带内有动态范围，TL 调参入口）；「未写完笔画 0 分」与「梦魇缺笔整字归零」**依附限时开关**；完成度用与难度无关的宽松容差（DONE_TOL 系）判定。
5. **InkBox 是闭包工厂**：多实例分屏的前提；坐标唯一事实源 = 屏幕坐标等比映射到 0..400，不偏移。
6. **存储 schema（STORE_KEY='dgms_dazhuan_v1'）**：`{ver, solo[], duo[], roster[], lib, ach{}, soloName, rubBy{玩家名:{字:最高分}}, seenBy{玩家名:巡游已展示数}}`。**拓片按玩家归属**（增量㉜）：旧版全机 `rubbings`/`rubTourSeenN` 由 loadDB/importDB 迁移函数自动迁入「我」名下后弃用；**导入=按玩家合并**（同名覆盖、他人保留）。**给 DB 加/撤任何字段必须同步 loadDB 与 importDB 两处重建白名单**（此坑踩过三次）。**导入语义=合并保最佳，绝不整替（增量㊶定稿）**：solo/duo 逐条 keepBest（同名同难度取最佳）+dedupeList、eggRec 按模式逐列表 keepBest、roster 并集去重、ach 取并集——旧档导入绝不回滚本机新成绩；"以文件为准全量替换"用「清空本榜 → 导入」两步等效达成（toast 明示"合并保最佳"）。
7. **双人混合赛**：plan 数组（辨铭抢答 d 轮 + 写铭描红 t 轮，PK_ROUNDS 随难度 6+4/9+6/12+8）；分数制对局（先答 +15/后答 +10；描红按分累加）；共享血条按得分占比，≥56% 爆闪 / ≤44% 呼吸 / 分割点闪电；**两侧选项独立洗牌**（防后手抄位置——比参考版同序更强，勿回退）；辨铭字避开写铭字。
8. **双人触屏**：`#s8{touch-action:none}` 整页禁手势（根因：任一指触画布外 auto 区即激活 pinch/滚动，手势状态机吞掉全部新触点）。
9. **巡游触发与节奏（按玩家）**：拓片墙 rub 页渲染时 `该玩家已拓数 > DB.seenBy[该玩家]` ⇒ 播金框巡游并落 seenBy（"有未展示过的解锁字即巡游"）；节奏=**每秒 1 行**（行内均分快闪，脉冲时长随槽位压缩）；快闪=金色脉冲（亮度≤1.12+饱和金边，杜绝白光）；扫完**整页收束金光 1s**（仿铸鼎 dingFlash）后滚回墙顶。
10. **出题去重生命周期=一局**（增量㉚㉛ 何何老师定稿）：识铭 6 字先选、辨铭 4 字从「相似池 − 识铭已用字」选 ⇒ **同局认字零重复**；**结算页出现即该局去重作废**，下一局/下一位玩家从头再来（局内存量，不落库）。
11. **结算页内嵌榜单**：`boardTableHTML(tab, limit, diffFilter)` 一份渲染两处用（拓片墙 12 条 / 结算页 top5），本轮记录由 lastTs 高亮；「点亮拓片数」列=该玩家实时实拓数（活算不落快照，随通关持续刷新）。**榜单按难度分档（2026-10-08 何何老师定稿）**：三档实力不可比不混排——拓片墙 solo/duo 页签下挂 `.diffTabs` 难度子榜（`BOARD_DIFF` 记忆、DIFF_ORDER 动态生成、子榜无「关卡」列）；结算页内嵌=本局难度过滤；「展开完整榜单」直达本局难度子榜。
12. **结语金句池**：TIERS 四档各 4 条结语预案 + `goldLineOf(score)` 按档随机（梗词 {m} 联动 + 上句防重），单人点评与双人平手结语共用；原金句收编为宗师档预案之一（不再每局必现）。
13. **参赛名字**：封面「参赛名字（学号）」输入框 → CUR.playerName 贯通对局与榜单（finishSoloSave 用真名，留空=「我」）；拓片归属/榜单行/出题去重均以此为玩家键。
14. **铸鼎落字随机化**：落字顺序洗牌；来向四向随机（上/下/左/右 × 距离 60~130px + 垂直抖动 ±12px，经 CSS 变量 --dx/--dy 注入 charDrop 关键帧）；间隔 200~480ms 随机——各字仍落回自己的铭文槽位。
15. **彩蛋系统（增量㉝~㊴ 演进后现状）**：新屏 s13 世外桃源 / s14 点兵点将(落地+solo) / s15 点将PK / s16 点将结算（旧屏页码不动）。`EGG_PWD='PFLS666'` 源码常量（改口令=改 p5 一行）；`EGG_MODES` 注册表一份三处消费——**新增关卡只需往数组加一项 + 对应 go 渲染函数**。**勾选 = 纯内存态 `EGG_SEL`**（增量㉞ 撤销 DB.eggSel，刷新/关页即清，每次会话须重新勾选）；`DB.eggRec`（各模式成绩，含 diff 档位）在 loadDB/importDB 双白名单。播送带入口 `eggEntry()`：**达标 → 免口令窗直进桃源；未达标 → 零文字口令窗**（错口令仅抖动，input type=password 隐去）。
16. **点兵点将三档状态机（V3.2）**：`DIAN_TIERS` 数据驱动（菜鸟 3/6/9·不限时·cdn 5 步×1s / 困难 6/9/12·cdn×0.6s·限时 8/12/16 / 梦魇 6/9/12·cdn=['Go! Go!
