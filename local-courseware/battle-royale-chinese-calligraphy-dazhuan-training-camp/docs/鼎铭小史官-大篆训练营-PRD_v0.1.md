## 1. 一句话定位【设】

面向中学预备班书法课的课堂互动课件：以"西周小史官铸铭"角色扮演为叙事壳，让学生在**识铭、辨铭、写铭（描红）、铸鼎、双人 PK** 五类玩法中，学会约 36 个金文（大篆主体）的认读与书写，并理解汉字从商（甲骨）到秦（小篆）的**演变枢纽**地位。

## 2. 三部曲叙事（本项目存在的差异化理由）

```
商 · 甲骨小侦探（破译） → 西周 · 鼎铭小史官（铸铭） → 秦 · 篆刻工坊（镌印）
```

- 朝代分工天然清晰，从根上避免与两个姊妹课件内容撞车；
- 学生若玩过甲骨课，"你破译了商王的卜辞，现在晋升为西周史官，把功劳铸在鼎上传给子孙"——教学连续性是现成的桥；
- 三课同框即"汉字三千年"完整展线，母项目因此有了产品矩阵故事。【设】

## 6. 教学目标草案（框架待何何老师定稿）

- **T1 知道**：金文是铸/刻在青铜器上的文字，西周主流字体，上承甲骨、下启小篆；
- **T2 会认**：识铭——金文字形 → 楷书 4 选 1；
- **T3 会辨**：辨铭——相似金文字形甄别；
- **T4 会写**：写铭——描红临摹，感受金文**肥笔、圆转、块面感**（与小篆匀一线条的本质区别，也是本课美术训练点）；
- **T5 懂文化**：青铜礼器常识（鼎/簋/盘）、铭文套语（如"子子孙孙永宝用"）、六书在金文中的体现；
- 课时目标拆分：待 Q7 拍板后细化到两课时。

### 7.2 bronze 35 字单（实测抽取自 v6.6.618 的 GLYPHS4.bronze）

```
一二三上下十口刀弓土小中石王日子八七木目耳手心田水山立贝从好林明家鸟鱼
```

与 36 字训练集相比**缺"火"**——首版扩字时补齐。【实】

### 7.3 关键复用结论（本 PRD 最重要的技术判断）

1. `glyphData(ch)` 描红管线 = `rasterizeGlyph → skeletonize → chainTrace`，**从 SVG 填充轮廓运行时现算中心线骨架**，不存在独立笔画中线数据【实，读源码确认】；
2. bronze 字与 seal 字**同格式**（同 viewBox、同 path 数组结构）→ **35 个金文字零数据转换即可进描红引擎**【实】；
3. 但评分参数（MIN_CHAIN、DONE_COV、容差带、T_LIMIT 限时模型）是按小篆匀线条调校的；金文**肥笔的骨架分叉会让 frags（碎链）增多、覆盖度判定变严**——判定是否公平**必须真机实测校准**，不允许纸面拍板【待 → §12 Phase 0 第一项】。

## 8. 字库方案

- **首版规模**【设】：36 字三阶（≈18/12/6），以 bronze 35 字起步 + 补 1 字同档字（候选"火"，以实际字形质量定）；
- **字形来源**【待】：现成 35 字零成本；扩字走**参考图矢量化**已验证管线（SOP v2 §4，3.1KB/字、零字体授权风险）；**金文拓片参考图的可用来源未经我手验证，Phase 0 验证前不承诺任何扩容字数**；
- **字源文案**【待】：《说文》式讲解的**结构**可继承（象形/指事/会意分类 + 段落模板），但 36 段文案需按**西周语境**重写（青铜器、铸铭、赏赐记功），工作量计入 Phase 1；
- **断言守护**：构建期断言"三阶配比 / 字数 / 每字四件套（字形+字义+六书+描红可用）齐全"，照搬 gen_data.py 构建即校验模式【实·模式已验证】。
