## A. 工作流 SOP（本项目日常循环）

### A1 改一行代码的完整闭环
1. 改 `src/` 分片（**禁止**直接改构建产物 HTML）；
2. `node tools/build.js` —— 构建期断言 + `node --check` 语法闸门；任何"先绕过断言交付"= 带病上线；
3. `node tools/test_main.js` —— 85 项真机回归；**断言随功能同增**（新功能必须带新断言；删除功能改墓碑断言）；
4. 计时/动画类断言失败 → **连跑 3 次**甄别抖动，3 中 3 绿=偶发，如实报告不改代码；
5. 交付：根目录 + `~/Downloads/` 双副本 MD5 一致。

### A2 触碰字形/字库后的强制动作
- 改了 GLYPHS/CHARS/DZINFO → **必须重跑 `node tools/calibrate.js`**（build 断言会拦截不一致）；
- 校准证据双写（/tmp + docs/归档），build 在 /tmp 缺失时自动回退 docs/ 副本——**不要再手工回拷**。

### A3 给 DB 加新字段的强制动作（三次踩坑的血泪）
`loadDB()` 与 `importDB()` 各有一份**重建白名单**——新增字段必须**同时**补进两处，否则刷新/导入即丢。
铁律：加字段前先 `grep -n "loadDB\|importDB"` 定位两处白名单，加完 `grep 新字段名` 双确认。

### A4 特效移植的强制动作
从姊妹课件移植任何 CSS 特效：**整块逐字复制参考版 CSS + keyframes**（含其修复史注释），替换前先 diff 自写版差异。教训：自写"看着差不多"的闪电丢了 clip-path 轮廓与粒子辉光（本会话实证）。

### A5 文件/项目改名的强制动作
1. `mv` 文件夹与文件；
2. `grep -rn 旧名 tools/ src/` → 逐处更新（build/test/shot 的 OUT 引用必中）；
3. 残留命中逐条分类：**代码注释与品牌名可保留**（课件名≠项目文件夹名），导出文件名等用户可见物按需决策；
4. 改完必跑 build+回归（引用断了当场暴露）。

## C. 内容口径（教学层，改文案前必读）

1. **金文 ⊂ 大篆（从属非等同）**：金文是载体概念（青铜器铭文），大篆是统称（广义含甲骨/金文/籀文，狭义=籀文，学界有分歧）。标注一律写「金文（大篆主体）」，不写"金文·大篆"并列。
2. **描红分数是"轮廓贴合度"数学分**，不是书法评价（中锋/笔力/气韵不评）——界面文案不得暗示"字写得好"。
3. **笔顺提示**：起笔编号点是骨架链端点，非严格笔顺（金文笔顺学术无定论）——文案写"落笔端点提示"。
4. 未验证的字形来源不承诺扩字字数（PRD R2）；「火」字缺位保留。
5. **古今形位差字（七/十）必须按古形教**：金文「七」=十字交叉形、「十」=一竖（中带绳结，EB26）——字形与今形"互换"，任何文案/答题反馈提到这两字都不得按今形描述（增量㉑实证：旧 desc"先横后竖交叉居中"教的正是反的）。判定文字与字形是否矛盾，**以 GLYPHS4 实际渲染形为准**，汉典变体比对作仲裁。
6. **拓片按玩家归属（增量㉜定稿）**：首页计数/字表标记/拓片墙/巡游触发/榜单「点亮拓片数」列全部以**参赛名字**为键（rubBy/seenBy 分档）；新玩家首次=0 属正常；导入=按玩家合并（同名覆盖、他人保留）。
7. **出题去重生命周期=一局（增量㉚㉛定稿）**：识铭∪辨铭同局互斥选字（辨铭池=相似池−识铭已用），**结算即作废**、下一位玩家从头再来；写铭与认字的重叠有意保留（识→辨→写教学闭环）。
