## 1. 项目是什么

何何老师@PFLS 的课堂教学专用「大篆训练营」互动课件应用。一个域名下两个入口：

- **导航页**（`index.html`，应用首页）：置顶互动游戏卡片槽位墙，可拖动换位、超出 10 个自动折叠、右上角背景切换器（含密钥解锁 + 网页动态特效子菜单）；
- **互动课件**（`course.html`）：大篆描红/游戏课件本体，进入前有访问门禁（密钥 `zyywz`）。

线上地址：**https://omg-its-hehelaoshi-training-camp.app.workbuddy.host/**（appId `wbapp_QPd4KJWjk8qMYcQLjRhaa7`，sandbox `6e516d6f4d374fdc9a5278de41ab3d62`，自 2026-10-14 起未变）

## 3. 导航页功能清单（index.html）

1. **大标题**「何何老师多合一专题训练营」：逐字拆分 + 波浪式延迟浮动（`titleFloat` 10.4s，**只上浮不下沉**）+ 流动渐变，小学生手写字体（`XiaoXueShengShouXie`，woff2 子集化 base64 内嵌，**不依赖用户装机字体**）。
2. **标语播送带**：48 字标语无缝循环滚动，复刻课件封面「每副本 = 一整带宽」结构，运行时按带宽实测收紧字号（保证任何视口下整句完整可见）。
3. **卡片槽位墙**：默认 5 个一排（1 个置顶课件卡 + 3 个虚位以待 + 1 个「添加课件位」）；同屏最多 10 个，超出折叠为「更多课件（n）」小按钮；卡片可**鼠标拖动交换位置**（顺序持久化 localStorage）；点击课件卡进入 `course.html`，点击虚位卡弹 toast「虚位以待，敬请期待～」。
4. **置顶卡视觉**：半透明毛玻璃 + 动态渐变流动（`background-position` 驱动，图层恒等覆盖，任何时刻不露底）+ 悬停「一闪而过」高光。
5. **背景系统**：`bg.jpg` 自然比例横带（零失真）+ 高斯模糊缝合层 + 水色渐变 + 5 个中心的伪 3D 涟漪套装（每中心 1 微光 core + 3 柔环：2 同径错峰 + 1 大径，`scaleY` 椭圆压扁 + 扩张衰减 + blur）。
6. **猫形遮挡层**（`.bgCat`）：猫身 RGBA 切图覆于涟漪之上——猫身遮挡涟漪（物理正确：实体猫挡住水面涟漪）；随背景切换联动换图，导入的自定义背景无猫形则自动隐藏。
7. **背景切换器**（右上角 🎨 按钮，38×38 纯图标圆钮）：密钥 **`zyywz2026`**（z-y-y-w-z，勿写错）解锁 → 菜单内可切换内置背景、导入本地图片（自动降采样 1920 宽存 localStorage）、删除导入图、勾选「智能拉伸图片至满屏」。偏好持久化（localStorage `hehe-bg-switch-v1`），刷新保持；点面板外自动关闭。
8. **网页动态特效子菜单**（`#fxSec`，面板内）：**注册表驱动**——JS 里 `FX = [{id,name,layer,def}]`，新增特效 = 加一个效果层 DOM + 数组登记一行，面板自动长出勾选项；多选叠加（各层独立 display 显隐）、可全关；偏好存 localStorage `hehe-fx-switch-v1`（与背景偏好分开）；默认「水面涟漪」勾选并带「默认」徽标。
9. **口令框风格**：面板密码框/解锁按钮复刻课件 V3.2 彩蛋口令窗（源：课件第 484-495 行 `#eggIn`/`#eggGo`）——深底 `rgba(20,16,10,.92)` + 2px 金框 `#c9a227` + 金字 `#e8c96a` + 楷体宽字距居中；解锁按钮为向右箭头 **➜**（U+279C，与课件同字符）；密码框**无占位符文字**（第 15 轮按用户要求移除）。
10. **「浦外」角标**：大标题「师」「多」二字之间的浮动角标，三层结构（框/填充/字）：外框 = 滚动标语同款橙渐变 + 高光流光；框内填充 = 当前背景图同款水色渐变（canvas 动态采样，切背景/拉伸/resize 自动重采）；框内字 = 标语橙渐变（不滚动）；**与大标题同相浮动**（详见 SOP 文档）。定位由 `placeBadge()` 运行时按墨迹常数计算。

- 密钥 **`zyywz`**，输错抖动提示；「‹ 返回导航页」按钮可退回首页（`location.href='index.html'`）。

## 5. 安全边界（如实说明）

- **门禁密钥与切换器密钥均为前端校验**（源码可见）：能防误触、防普通学生，**防不了刻意破解**。教学场景够用；若需真权限控制，后续应加服务端校验（本仓库数据不含任何服务端代码）。
- 本应用为公开静态托管，任何人可访问页面与静态资源。

## 7. 回滚点

| 场景 | 回滚方法 |
| --- | --- |
| 导航页改坏 | 本地留档链（见下）取改前一刻的 `.bak` 覆盖 `index.html` 再发布 |
| 背景想换回旧图 | `cp bg-src.png bg.jpg`，并把 `--art-h` 改回 `calc(100vw * 273 / 918)` |
| 想移除背景切换器 | 删除 `#bgBtn`/`#bgPanel` 相关 HTML+CSS+JS 块 + 清除 localStorage 键 `hehe-bg-switch-v1` / `hehe-fx-switch-v1` |
| 想移除猫形遮挡层 | 删 `.bgCat`（HTML 一行 + CSS 一块 + JS 两函数联动）+ 删 cat-cut*.png |
| 想移除浦外角标 | 删 `.titleBadge` 相关 HTML+CSS+JS 块（创建/定位/填充采样三处） |
| 课件改坏 | 本地版仓库 `git checkout` 重建，或本仓库 local-courseware 快照 |
| 发布目标异常 | 见 SOP：修正 `.workbuddy/applications.yaml`（备份 `.bak-20261014-0025` 可还原） |

## 8. 维护约定

1. 每次改导航页必须更新 `<meta name="build">` 戳（格式 `NAV-YYYYMMDD-HHMM`），它是线上核验的锚点。**已知流程偏差**：第 15 轮（去占位符，2 行改动）未升戳即发布，靠 6 文件 md5 逐字节比对弥补——下不为例。
2. 两个部署目录（dazhuan-camp-sites / hehelaoshi-training-camp-sites）改动后**必须同步**（md5 对照）。
3. 原版课件 `趣味游戏互动HTML课件集/…/铸铭问鼎论英雄-大篆训练营-V3.2.html` 只读参照，禁改；课件改动走本地版仓库 src 模块构建。
4. 同步本仓库时：deployed/ 用发布目录干净快照覆盖（不含 .bak）；local-courseware/ 用 `git archive HEAD` 从本地版仓库导出覆盖。
5. 新增网页特效 = 效果层 DOM + `FX` 数组登记一行，不要改面板结构（注册表驱动，见 SOP）。
6. 改动角标几何前先读 `docs/导航页视觉与特效-SOP.md` 的「同相浮动」章节——墨迹常数与相位约束是硬约束。
