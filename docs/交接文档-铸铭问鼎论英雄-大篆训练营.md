## 1. 项目是什么

何何老师@PFLS 的课堂教学专用「大篆训练营」互动课件应用。一个域名下两个入口：

- **导航页**（应用首页）：置顶互动游戏卡片槽位墙，可拖动换位、超出 10 个自动折叠、右上角背景切换器；
- **互动课件**（`course.html`）：大篆描红/游戏课件本体，进入前有访问门禁（密钥 `zyywz`）。

线上地址：**https://omg-its-hehelaoshi-training-camp.app.workbuddy.host/**

## 2. 文件清单（deployed/dazhuan-camp-sites/）

| 文件 | 作用 | 备注 |
| --- | --- | --- |
| `index.html` | 导航页（约 48KB，单文件自包含） | **应用首页**，根路径打开的就是它；`<meta name="build">` 记录版本戳 |

`deployed/hehelaoshi-training-camp-sites/` 为主目录逐字节副本（应急时改发布目录指向它即可）。

## 3. 导航页功能清单（index.html）

1. **大标题**「何何老师多合一专题训练营」：上下左右浮动动画 + 流动渐变，小学生手写字体（子集化 woff2 内嵌）。
2. **标语播送带**：48 字标语无缝循环滚动，复刻课件封面「每副本 = 一整带宽」结构，运行时按带宽实测收紧字号（保证任何视口下整句完整可见）。
3. **卡片槽位墙**：默认 5 个一排（1 个置顶课件卡 + 3 个虚位以待 + 1 个「添加课件位」）；同屏最多 10 个，超出折叠为「更多课件（n）」小按钮；卡片可**鼠标拖动交换位置**（顺序持久化 localStorage）；点击置顶卡进入 `course.html`，点击虚位卡弹 toast「虚位以待，敬请期待～」。
4. **置顶卡视觉**：半透明毛玻璃 + 动态渐变流动（`background-position` 驱动，图层恒等覆盖，任何时刻不露底）+ 悬停「一闪而过」高光。
5. **背景系统**：`bg.jpg` 自然比例横带（零失真）+ 高斯模糊缝合层 + 水色渐变 + 5 个中心的伪 3D 涟漪套装（每中心 1 微光 core + 3 柔环：2 同径错峰 + 1 大径，`scaleY` 椭圆压扁 + 扩张衰减 + blur）。
6. **背景切换器**（右上角 🎨 按钮）：密钥 `zyywz` 解锁 → 菜单内可切换内置背景、导入本地图片（自动降采样 1920 宽存 localStorage）、删除导入图、勾选「智能拉伸图片至满屏」。偏好持久化，刷新保持；点面板外自动关闭。
7. **版权行**：Copyright © 2026 何何老师@PFLS. All rights reserved.

## 4. 课件门禁（course.html）

- 密钥 `zyywz`，输错抖动提示；「‹ 返回导航页」按钮可退回首页。
- 课件本体为单文件 HTML，含大篆描红、游戏模式、校准数据等完整功能（源码见本地版仓库 `src/`）。

## 5. 安全边界（如实说明）

- **门禁密钥与切换器密钥均为前端校验**（源码可见）：能防误触、防普通学生，**防不了刻意破解**。教学场景够用；若需真权限控制，后续应加服务端校验（本仓库数据不含任何服务端代码）。
- 本应用为公开静态托管，任何人可访问页面与静态资源。

## 6. 发布方式（重要）

- 发布工具：WorkBuddy 发布技能；参数：`directory=~/My-Projects/dazhuan-camp-sites`，`language=static`，`domainPrefix=OMG-its-hehelaoshi-training-camp`，**不传 entryHtml**（单应用自动识别 index.html），**不传 startCmd**。
- 发布成功后**必须立即探针核验**：根路径 build 戳、bg.jpg 可达、旧应用（hehe-studio-all-in-one.app.workbuddy.host）未被覆盖。
- 历史事故与毒源定位方法已蒸馏为 `docs/发布目标解析排障-SOP.md`，发布异常时先读它。

## 7. 回滚点

| 场景 | 回滚方法 |
| --- | --- |
| 导航页改坏 | 本地留档 `index.html.bak-20261014-r4`（改坏前一刻）覆盖 `index.html` 再发布 |
| 背景想换回旧图 | `cp bg-src.png bg.jpg`，并把 `--art-h` 改回 `calc(100vw * 273 / 918)` |
| 想移除背景切换器 | 删除 `#bgBtn`/`#bgPanel` 三块（HTML+CSS+JS 均为独立新增块）+ 清除 localStorage 键 `hehe-bg-switch-v1` |
| 课件改坏 | 本地版仓库 `git checkout` 重建，或本仓库 local-courseware 快照 |
| 发布目标异常 | 见 SOP：修正 `.workbuddy/applications.yaml`（备份 `.bak-20261014-0025` 可还原） |

## 8. 维护约定

1. 每次改导航页必须更新 `<meta name="build">` 戳（格式 `NAV-YYYYMMDD-HHMM`），它是线上核验的锚点。
2. 两个部署目录（dazhuan-camp-sites / hehelaoshi-training-camp-sites）改动后**必须同步**（md5 对照）。
3. 原版课件 `趣味游戏互动HTML课件集/…/铸铭问鼎论英雄-大篆训练营-V3.2.html` 只读参照，禁改；课件改动走本地版仓库 src 模块构建。
4. 本地 .bak 留档只存本地，不进仓库、不发布。
5. 同步本仓库时：deployed/ 用发布目录干净快照覆盖；local-courseware/ 用 `git archive HEAD` 从本地版仓库导出覆盖。
